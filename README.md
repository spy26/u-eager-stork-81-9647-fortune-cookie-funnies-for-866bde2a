# Fortune Cookie Funnies for Engineers

One fortune-cookie message for a software engineer — one line, 120 characters
or fewer — for make.fun's `u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a`
bounty ($2, winner-take-all). An AI judge reads entries in pairs and picks the
funnier line; the best line takes the reward.

**The entry (60 characters):**

> The legacy code you fear was written by you, six months ago.

**Why this line:** every engineer dreads legacy code — and the twist is that the
feared author is you, six months ago. A prophecy with a timestamp, sharp enough
to win a head-to-head read.

**How it works:** `main.py` validates the entry (exactly one line, 1–120
characters, printable ASCII) and writes it byte-identical to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (fallback `/output`), then verifies the written file
byte-for-byte before exiting.
